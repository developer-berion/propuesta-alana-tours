# Alana Tours | Estrategia Comercial B2B

## Descripción
Este proyecto es una presentación interactiva tipo "deck" diseñada para presentar una estrategia comercial B2B para Alana Tours. Utiliza un diseño moderno y cinemático para exponer la propuesta de valor, diagnóstico, solución y hoja de ruta de crecimiento.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica del documento.
- **Tailwind CSS (CDN):** Framework de utilidades para el diseño visual, incluyendo configuraciones personalizadas para la paleta de colores de la marca.
- **Lucide Icons:** Iconografía moderna y escalable.
- **JavaScript (Vanilla):** Lógica para la navegación entre diapositivas, animaciones de entrada y gráficos dinámicos.
- **Python (Pillow):** Scrip de utilidad (`generate_favicons.py`) para generación de assets.

## Configuración de Privacidad y Assets
- **No-Index:** Implementación de meta tags `noindex` y archivo `robots.txt` para evitar rastreo público.
- **Favicon:** Sistema completo de iconos generado dinámicamente para soporte multiplataforma.
- **Mobile Gatekeeper:** Sistema de restricción estricta que bloquea el acceso en dispositivos móviles y tablets para garantizar la experiencia de usuario diseñada para escritorio.

## Estructura del Contenido
La presentación consta de 5 secciones principales:
1.  **Introducción:** Propuesta de valor "Optimización Comercial B2B Inteligente".
2.  **Diagnóstico:** Análisis de los retos actuales (Dependencia, Visibilidad, IA).
3.  **Solución:** Los 5 pilares de la metodología Berion (SEO, Promociones, Contenido, IA, Inteligencia).
4.  **Hoja de Ruta:** Cronograma de implementación (Estabilización, Visibilidad, Expansión).
5.  **Impacto:** Proyección de retorno de inversión (ROI) y cierre.

## Cómo Ejecutar
1.  Abra el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
2.  Navegue a través de las diapositivas utilizando:
    - Las flechas de dirección del teclado (Derecha/Izquierda).
    - La barra espaciadora (Siguiente).
    - Los botones de navegación en pantalla.
    - Los puntos de paginación en la parte inferior.
